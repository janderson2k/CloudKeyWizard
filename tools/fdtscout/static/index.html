Docker

      
Run your own containers on this device. This is a general-purpose container manager, not tied to any one app -- Home Assistant's own Docker container (if you installed that Extra) shows up on the Apps tab as usual, unaffected by anything here. Deliberately out of scope: compose stacks, an exec-into-container shell, Docker Hub image search, network/volume management, and bulk operations -- this hardware's RAM and storage are tight enough that a full dashboard would invite more trouble than it's worth.

IP address

      

      
A changed IP is provisional for 5 minutes -- if you don't confirm it (a splash appears once you can reach the device at its new address), it automatically reverts to what it was before. A wrong gateway/subnet can still make the device briefly unreachable during that window; that's expected, not a sign something's broken.

      

        
        
        
        
      

      


      
DNS

      

      
Applied immediately, no confirmation window -- a bad DNS server affects this device's own outbound lookups, but not your ability to reach this console by IP (that's your browser's own DNS, not the device's).

Timezone

      
Affects log timestamps and cron/scheduled-task timing on this device -- not NTP (that's what keeps the clock accurate; this is what zone it's displayed in).

      

        
        
      

      


      
Pushbullet

      
Proactive alerts, plus a two-way callsign command channel -- text this device's callsign (e.g. "SCOUT001 status") from your Pushbullet app and it replies. The API token comes from Pushbullet's own Settings → Account → Access Tokens page -- never your Pushbullet login.
